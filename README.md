# Countdown Timer 

A beginner-friendly countdown timer built with **HTML, CSS, and JavaScript**.  
It counts down from 1 minute and shows a message when the time ends.

##  Concepts Practiced
- Using `Date.now()` to calculate remaining time
- Updating the timer every second with `setInterval()`
- Formatting time using `String.padStart()`
- Clearing intervals to stop negative values
- Dynamic style changes using `classList.add()`

##  Preview
Displays a heading “WE'RE LAUNCHING SOON” with a timer below it.  
When time ends, the background color changes and the message appears:  
**“The wait is over! 🎉”**

## ⚙️ Technologies
- HTML5  
- CSS3  
- JavaScript (Vanilla)
